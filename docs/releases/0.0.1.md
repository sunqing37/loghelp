# LogHelp 0.0.1

首个公开版本：独立的 Android Logcat 桌面工具。2026-10-14 更新 `r3` 修订包，应用版本仍为 `0.0.1`，内嵌修订号为 `3`。

## 本次修订

- 检查更新同时比较产品版本和整数修订号；同版本的更高修订可以直接下载、校验、替换及重启。
- 修复设备选择等弹窗默认高度不足导致内容截断，长内容保持滚动、底栏固定。
- 新增 `.agent` 协作规范、GitHub 发布步骤、安全提交脚本及统一打包工具。

旧 `r2` 只比较产品版本，不能识别同为 `0.0.1` 的 `r3`；首次需要手动下载、退出旧程序并替换。使用 `r3` 后，后续同版本 `r4` 等修订能够在应用内更新。历史附件保留用于回溯。

## 下载和启动

- 优先下载 `loghelp-0.0.1-windows-amd64-r3.zip`，解压后运行 `loghelp.exe`，无需安装 Go 或 Android Studio。
- 安装 Android SDK Platform-Tools，将 ADB 加入 PATH，或在 LogHelp 设置中选择 `adb.exe` / platform-tools 目录。
- 连接设备、开启 USB 调试，并在设备上确认调试授权。
- Windows 中文界面优先使用系统微软雅黑字体，日志优先使用 Consolas。

附件 `SHA256SUMS-r3.txt` 提供修订包的 SHA-256，解压后的 `SHA256SUMS.txt` 提供 EXE 的校验值。包内 `VERSION`、`REVISION` 和 `release.json` 记录版本、修订和来源。PowerShell 校验示例：

```powershell
Get-FileHash .\loghelp-0.0.1-windows-amd64-r3.zip -Algorithm SHA256
```

## 主要功能

- 窗口标题、主界面顶部和设置页显示 `0.0.1 r3`。
- 设置页的“检查更新”打开独立弹窗，显示 GitHub 最新正式版本和发布说明摘要；关闭后返回原设置页并保留未保存内容，网络失败时显示提示。
- Windows EXE 嵌入与窗口一致的蓝色 `L` 图标。
- Windows 便携版有新版时可“下载更新并重启”：确认结束采集、录制和终端后，下载并校验 SHA-256，由独立更新进程替换 EXE 并重启；替换或启动失败时恢复旧程序。程序目录需要可写，重启前需保存设置。
- ADB 设备发现、实时采集、多标签页及共享采集。
- 字段过滤、正则查询、搜索高亮、上下文和时间跳转。
- 多行合并、详情换行、拖选及复制。
- 本地录制、分段与目录额度管理、离线阅读和导出。
- 设备交互 Shell、深浅色主题及快捷键设置。

## 验收范围和已知限制

- 修订包基于当前源码、版本和修订号的成功构建记录生成，打包时核对 EXE 哈希，不重复编译。
- 已完成 Windows 启动、真实设备采集、过滤/搜索、共享采集、录制/离线分页及 Shell 连接的基础手动检查。
- 部分详情选择及快捷键交互仍待实际操作验收，具体范围见仓库的 [手动验收记录](../../docs/manual-validation.md)。
- macOS/Linux 目前仅有模块编译验证，本次不提供这些平台的二进制附件。
- ADB 和字体使用系统环境，不随程序捆绑。此版本不提供安装器；应用更新由用户点击确认，不在启动时自动检查或安装。

完整使用说明见 [README](../../README.md)。
