# LogHelp 0.0.5

产品版本 `0.0.5`，内嵌修订号 `0`，从 `0.0.4` 升级。源码标签 [v0.0.5](https://github.com/sunqing37/loghelp/tree/v0.0.5)。历史 Release 与附件保留。

## 本次更新

- 离线打开支持 ZIP/TAR/Gzip/Bzip2/Zstd 压缩包及组合格式，后台解压、解码、索引并合并日志。内置腾讯 Mars xlog 解码，支持未加密及配置私钥后的加密 Deflate/Zstd；其他格式可配置本机解码工具。
- 普通 JSONL 自动识别正文、级别、时间字段，也可配置顶层字段映射；保留完整原文与大整数。详情显示来源文件、归档条目和行号，支持来源过滤与复制；解码内容标注解码后行号。
- 导入显示解压、解码、索引阶段及处理量，底部可直接取消；导入报告展示跳过条目及解析、解码警告。
- 日志详情新增「复制 JSON」，提取第一个有效 JSON 对象或数组，去掉日志前后缀并格式化复制。长 JSON 日志支持跨毫秒续接，仍按来源、连续性及大小限制合并。
- 日志列表和详情滚动条支持拖动滑块、点击轨道定位；手动滚动列表停止跟随最新。
- 日志侧栏新增默认关闭的「跟随顶部应用」，按当前日志设备自动更新包名筛选，按标签保存开关。
- 设备预览跟随原设备上下线，恢复可用后自动连接一次并保留暂停状态；持续在线的投屏故障保留手动重连。录屏断线按原流程收尾，恢复后需手动重新录屏。
- 设备预览新增默认开启的文本剪贴板双向共享，支持中文、表情及换行；首次连接不覆盖已有内容，关闭共享、离线或切换设备取消旧会话。图片和文件不参与文本共享。

解压与解码有资源、超时及取消限制。Mars 加密日志需自行准备匹配的密钥；设置只保存密钥文件或环境变量引用。普通 JSONL 字段映射修改后重新打开来源生效。

## 升级与运行依赖

Windows x64 便携版和当前用户安装版可从设置页「检查更新」，下载对应 ZIP、校验 SHA-256 后替换并重启，保留配置和录制文件；Setup 单独提供下载。Windows ARM64、macOS、Linux 手动下载对应附件。升级前保存设置；手动替换或安装前退出旧程序。

本次为产品版本升级 `0.0.4 → 0.0.5`，旧版按版本号识别更新。

ADB 需另行准备。Windows x64 内嵌 scrcpy 服务与 FFmpeg 解码库；其他架构/平台投屏需匹配架构的 FFmpeg（可执行程序需 5+，原生动态库需兼容 FFmpeg 7）。Linux 需要图形桌面及系统图形库，文件选择需 zenity/matedialog/qarma，剪贴板需 wl-clipboard 或 xclip。安装 APK 以外的 AAB/官方 APKS 仍需自行配置 Java/bundletool。详见包内 README 和 `docs/mirror-runtime.md`。

## 验收范围

本次更新沿用各功能已有的手动验收记录；JSONL、来源定位和导入进度的 Windows 运行证据见 [手动验收记录](https://github.com/sunqing37/loghelp/blob/v0.0.5/docs/manual-validation.md)。用户反馈不推定覆盖所有异常路径；剪贴板同时复制等后续边界修正仍待实机验收。

六平台 CGO=0 桌面构建通过，Windows x64 隔离环境启动、主界面及版本 `0.0.5 r0` 显示检查通过，详情见同一验收文档。包内记录源码 commit、版本、修订和程序 SHA-256，Unix 程序保留执行权限。macOS、Linux 和 Windows ARM64 由 Windows 主机交叉构建；未重新执行这些系统运行、全部设备功能、安装器实装及自动更新替换回滚流程。
