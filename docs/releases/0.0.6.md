# LogHelp 0.0.6

产品版本 `0.0.6`，内嵌修订号 `0`，从 `0.0.5` 升级。源码标签 [v0.0.6](https://github.com/sunqing37/loghelp/tree/v0.0.6)。历史 Release 与附件保留。

## 本次更新

- 新增右侧设备文件管理：树形浏览目录、路径跳转、筛选、键盘导航及普通文件上传下载；唯一在线设备自动选择，目录批量读取提速。支持取消传输和同名覆盖确认，无权限目录直接显示提示及错误详情。
- 文件管理与设备预览共用右侧区域，切换时保留投屏和录屏，收起面板后传输继续。遵循 ADB 权限，不自动 root，不递归传输目录或下载符号链接。
- 终端支持历史回滚、拖动滚动条、快捷键翻页及跨行选择复制；无选区时 Ctrl+C 保留中断语义，断线后仍可查看历史。
- 应用安装显示当前包、文件、实际发送进度和耗时；修复 Windows 二进制传输遇到特殊字节时截断的问题，传输完成后单独等待设备安装结果。
- 调整日志工作区的主题对比、筛选卡片、日志行高和工具栏自适应布局，长路径和状态单行省略；调整窗口大小时弹窗重新布局并居中，保留未保存输入。
- 修复 Wi-Fi ADB 连接标识变化后投屏和截图失效的问题，失效时重新选择在线设备；断联重试期间准确显示「等待重连」。
- 修复实时日志刷新时右下角「取消任务」按钮闪现；导入、离线扫描和显式分析任务仍保留取消入口。

## 升级与运行依赖

Windows x64 便携版和当前用户安装版可从设置页「检查更新」，下载对应 ZIP、校验 SHA-256 后替换并重启，保留配置和录制文件；Setup 单独提供下载。Windows ARM64、macOS、Linux 手动下载对应附件。升级前保存设置；手动替换或安装前退出旧程序。

本次为产品版本升级 `0.0.5 → 0.0.6`，旧版按版本号识别更新。

ADB 需另行准备。Windows x64 内嵌 scrcpy 服务与 FFmpeg 解码库；其他架构/平台投屏需匹配架构的 FFmpeg（可执行程序需 5+，原生动态库需兼容 FFmpeg 7）。Linux 需要图形桌面及系统图形库，文件选择需 zenity/matedialog/qarma，剪贴板需 wl-clipboard 或 xclip。安装 APK 以外的 AAB/官方 APKS 仍需自行配置 Java/bundletool。详见包内 README 和 `docs/mirror-runtime.md`。

## 验收范围

沿用各功能已有手动验收记录，详见 [手动验收记录](https://github.com/sunqing37/loghelp/blob/v0.0.6/docs/manual-validation.md)。设备文件管理、弹窗缩放等已有用户验收反馈；取消按钮修复已完成 Windows 编译，尚未获得 GUI 手动验收结果，不推定覆盖全部异常路径。

六平台 CGO=0 桌面构建通过，源码指纹和二进制哈希一致；Windows 命令行核对内嵌版本为 `0.0.6 r0`。macOS、Linux 和 Windows ARM64 从 Windows 主机交叉构建，不代表已完成这些系统的运行验收；本轮不重复安装器实装及自动更新替换回滚流程。包内记录源码 commit、版本、修订及程序 SHA-256，Unix 程序保留执行权限。
