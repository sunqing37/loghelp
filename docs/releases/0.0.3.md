## 录屏与截图

- 设备预览新增 MP4 开始/停止录屏及计时。折叠屏内外屏切换、展开/折叠、旋转和分辨率变化后继续写入同一个文件，等待新关键帧时显示「切屏中」。暂停显示仍继续录制；关闭、重连、切换设备或正常退出时收尾保存。
- 「录屏设置」可选显示触控、录制系统声音、保留设备播放及结束后定位文件。声音/触控默认关闭，保存成功后自动定位视频默认开启，触控设置在录屏会话结束后恢复。
- 系统声音录制需 Android 11+，Android 11 起录时需解锁；保留设备播放需 Android 13+，低版本可关闭此选项。录入设备播放声音，不录麦克风；应用禁止采集时可能录到静音。
- 修复部分多屏设备在 PNG 前返回警告文字导致无法截图，保留原分辨率、完整 PNG 校验和系统图片剪贴板。
- 视频画质与预览一致，最长边上限 1280。切屏视频使用动态分辨率 avc3 MP4，播放器需支持参数更新；切屏后 15 秒仍无关键帧时结束并保存此前片段。

## 日志排查与桌面体验

- 支持 Wi-Fi 扫码、配对码和地址连接；设备/应用列表可刷新，配对提示更完整。
- 新增快速过滤、书签及来源定位、毫秒时间差、可调上下文、大文件离线稀疏索引及取消定位、暂停新增计数、录制故障换目录恢复。
- 新增 JSON 层级查看和复制、日志概览与异常导航、问题包预览与导出、关键词触发留证、拖入文件及最近文件、排查方案、缓存接收时间范围。
- 新增单实例、安全重启、跟随系统主题、更新代理与失败重试、本地诊断和问题反馈导出；反馈和问题包不自动上传。

## 自动更新与运行依赖

Windows x64 的便携版和当前用户安装版可通过设置页「检查更新」下载匹配的 ZIP，校验 GitHub SHA-256 后替换并重启，保留用户配置和录制文件；更新失败可回滚。Setup 同时提供下载，但自动更新仍使用 ZIP。Windows ARM64、macOS 和 Linux 手动下载对应附件。

本次为产品版本升级 `0.0.2 → 0.0.3`，无需同版本修订识别；历史只比较产品版本的 `0.0.1 r2` 也可识别本次新版。升级前保存设置，手动替换或安装前退出旧程序。

ADB 需另行准备。Windows x64 内嵌 scrcpy 服务与 FFmpeg 解码库；其余架构/平台投屏需匹配架构的 FFmpeg（可执行程序需 5+，原生动态库需兼容 FFmpeg 7），通过 PATH、程序旁 `runtime/` 或 `LOGHELP_FFMPEG` 查找。录屏封装不另需 FFmpeg 程序。

Linux 需要图形桌面和系统图形库；文件对话框需 zenity/matedialog/qarma，图片剪贴板需 Wayland 的 wl-clipboard 或 X11 的 xclip。文件定位优先使用 FileManager1，缺少选择服务时通过 `xdg-open` 打开目录。详见包内 `docs/mirror-runtime.md`。

## 验收范围

各功能的实际手动证据及未覆盖边界见 [手动验收记录](https://github.com/sunqing37/loghelp/blob/v0.0.3/docs/manual-validation.md)。Windows 已有真实设备投屏、截图、录屏及触控恢复、MP4 音视频解码、文件定位和界面渲染记录；切屏与时间戳重置另有构造媒体样本。完整录屏按钮流程、持续播放时的音画同步、受限应用内录和长时间录制仍待补齐。

六平台采用 CGO=0 完整桌面构建，包内记录源码 commit、版本和程序 SHA-256，Unix 程序保留执行权限。macOS、Linux 和 Windows ARM64 为 Windows 主机交叉构建，尚未完成目标系统运行验收。安装/卸载和 ZIP 自动更新曾在隔离副本验收，本次正式包的实际验证范围以手动记录为准。
