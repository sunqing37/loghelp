# 发布说明 Markdown

版本更新弹窗使用后台 Chromium 浏览器排版，按当前主题和 DPI 显示结果，说明独立滚动。不会打开浏览器窗口或读取用户的浏览器登录资料。每次排版使用独立临时目录，完成、取消或关闭弹窗后退出本次浏览器进程。

## 支持范围

- CommonMark 文本排版：标题、段落、引用、嵌套列表、强调、代码、分隔线、转义、引用链接和图片。
- GFM：表格、左右/居中对齐、任务列表、删除线、网页和邮箱自动链接。
- GitHub 常见内容：NOTE/TIP/IMPORTANT/WARNING/CAUTION 提示块、Emoji 短码、脚注及返回链接、标题锚点、`details/summary` 折叠、HTML 换行和表格、用户提及及当前仓库问题引用。
- 文档扩展：定义列表、缩写、上下标、标记高亮、插入文字。
- 代码块：常见语言语法高亮。
- 数学公式：KaTeX 支持的 TeX 语法，支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`、GitHub 的 `$` + 反引号形式及 `math` 代码块。不是完整的 LaTeX 文档编译器。
- 图表：`mermaid` 代码块，由固定版本 Mermaid 渲染。语法错误显示提示及原文。

折叠块点击后在后台重新排版，保持原滚动像素位置。脚注和标题链接在说明内滚动跳转；网页和邮箱链接交给系统处理。任务框是发布说明的只读状态。Markdown 中的脚本、表单、嵌入窗口和事件处理器不会执行；链接协议仍受应用限制。

这是 Markdown 文档渲染，并不复刻 GitHub 网站的登录、权限、issue 数据卡片或文件专用交互预览。未做全量规范一致性认证；新增扩展应通过固定插件版本和人工样例确认，不以“支持所有 Markdown 方言”代替具体支持清单。

## 运行依赖

需要 Edge、Chrome 或 Chromium（建议当前受支持版本）。Windows 优先发现系统 Edge/Chrome；macOS 检查 `/Applications` 中的 Chrome、Edge、Chromium；Linux 检查 PATH 中的 Chromium/Chrome。可用环境变量 `LOGHELP_MARKDOWN_BROWSER` 指定浏览器可执行路径，各平台使用本机架构的浏览器。

缺少浏览器、系统策略禁止无界面运行、排版失败/超时或图像解码失败时，自动改用纯 Go 原生排版，顶部保留切换原因。取消检查和关闭弹窗不会启动兜底任务。

原生模式无需浏览器，保留标题、段落、嵌套列表、强调、行内代码/代码块、分隔线、任务列表、删除线、链接、脚注、定义列表及 GFM 表格；表格保留表头、边框、列内换行和左/中/右对齐，链接命中随换行和对齐移动。公式、Mermaid 代码块及 HTML 显示原文，图片显示替代文字；没有公式计算、图表绘制、HTML 折叠和代码语法高亮。需要完整效果时仍可打开发布页，下一次检查会重新尝试首选渲染。

Node.js 和 npm 仅用于开发时重建内嵌资源，应用运行和普通 Go 构建不需要它们。Markdown、Emoji、代码高亮、KaTeX 字体和 Mermaid 库均离线内嵌；远程图片仍需网络，加载失败显示替代文字。浏览器图片请求使用浏览器自身网络设置，与应用更新 API 的代理配置分别生效。

界面按需解码可见图像分片，限制 GPU 缓存。单次渲染最长 60 秒，输入最多 2 MiB，输出最多 32 Mi 像素；过大的说明提示打开发布页。公式超出 KaTeX 能力或图表语法错误时保留可见错误，不声称已正确渲染。

## 开发维护

源文件与精确依赖版本位于 `scripts/markdown/`，`package-lock.json` 固定 npm 包完整性。生成的 `internal/markdownassets/runtime.zip` 随源码保存，内含渲染代码、字体、第三方许可证及源文件哈希；构建脚本校验它与源文件一致，构建指纹也覆盖该 ZIP。

修改解析器、样式或依赖后执行：

```powershell
python -X utf8 scripts/prepare-markdown.py --build
```

该命令使用项目 `.tools/markdown-renderer` 安装锁定依赖并打包；不编译 Go 应用。普通桌面构建继续使用项目构建脚本，无需 npm 联网。升级依赖后应人工查看实际发布说明以及表格对齐、长链接、深浅色、公式、图表、脚注、折叠、失败和取消场景。
