## 本次更新

- 「设备预览」采用持续 H.264 视频流与触摸控制连接，配置最高 60 FPS，显示实际帧率；支持切换设备、暂停/重连、返回/主页/最近任务和唤醒。
- 截图独立获取原始分辨率，可保存 PNG 或复制图片到系统剪贴板；Windows、macOS、Linux 均有实现。
- 高 DPI 显示按实际像素绘制界面及字体，支持日志列宽拖动与保存。
- 输入框增加撤销/重做与双击选词；标签可拖动排序，日志支持上下键连续选择及视图锚点恢复。
- 提供六种平台/架构的完整桌面便携包，共用 Go 实现并保持 CGO=0。

## 运行依赖与升级

ADB 不随包分发，请安装 Android SDK Platform-Tools，在设置中选择 ADB，并在设备上开启 USB 调试、确认授权。

Windows amd64 内嵌固定版本 scrcpy 服务及 FFmpeg 解码库；其他包内嵌同一 Android 服务，投屏需本机可用的匹配架构 FFmpeg 5 或更高版本，可置于 PATH、程序旁的 `runtime/` 或通过 `LOGHELP_FFMPEG` 指定。兼容 FFmpeg 7 原生动态库时直接使用，否则调用 FFmpeg 可执行程序。缺失依赖会显示处理提示；截图不依赖视频解码器。详见包内 `docs/mirror-runtime.md`。

Linux 运行需要图形桌面（X11/XWayland）及系统图形库；文件对话框需要 zenity、matedialog 或 qarma。图片剪贴板在 Wayland 需要 wl-clipboard，在 X11 需要 xclip。中文显示需要系统中文字体，或设置 `LOGHELP_FONT`。

Windows amd64 可通过旧版设置页“检查更新”下载、校验并重启到 `0.0.2`。其他平台手动下载对应包；升级前保存设置并退出旧程序。历史 `0.0.1 r2` 的同版本修订识别限制不影响这次跨产品版本升级。

## 验收范围

六种 CGO=0 完整桌面产物已串行链接，打包核对源码指纹、目标架构、版本及二进制哈希，包内记录源码 commit，Unix 程序保留执行权限。

Windows amd64 已完成真实设备视频接收、界面显示及原分辨率图片剪贴板格式检查。macOS、Linux、Windows arm64 在本次 Windows 主机上交叉构建，尚未完成对应系统的启动、解码、交互及图片粘贴验收。触摸、旋转、暂停/重连和长时间动态画面的完整人工验收仍待补齐；配置上限不代表保证实际 60 FPS。详见 [手动验收记录](https://github.com/sunqing37/loghelp/blob/v0.0.2/docs/manual-validation.md)。
