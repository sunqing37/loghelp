## Why

需要一个独立于 Android Studio 的跨平台桌面日志工具，方便在多设备调试时持续采集日志、快速定位问题并保留现场。现有需求覆盖实时查看，但还需要统一断线重连、过滤与搜索、录制生命周期和离线分析的行为。

## What Changes

- 提供 Windows、macOS、Linux 桌面应用，使用 Go 实现 ADB 调用、日志采集、查询和存储。
- 自动从 PATH 发现 ADB；允许配置可执行文件路径，显示实际使用的路径和版本，提供配置校验与清晰的错误提示。
- 展示设备名称、序列号和状态，支持设备热插拔、断线后恢复，以及应用包名选择和应用重启后的进程跟踪。
- 持续采集所选缓冲区日志，支持暂停显示、独立停止采集、自动滚动、清屏、列配置、级别配色和完整多行堆栈。
- 提供接近 Android Studio Logcat 的过滤语法、历史和收藏；另外提供搜索、高亮、匹配导航、时间跳转和上下文查看。
- 支持指定目录录制完整采集流、文件轮转、容量管理、导出，以及离线打开已保存日志。
- 支持独立配置的多个标签页，同一设备共享采集；恢复标签页配置，明确后台录制与关闭标签页的关系。
- 提供绑定设备的交互式 Shell，支持输入、取消、终端尺寸调整、复制粘贴及本地命令历史。
- 使用有界显示缓存和虚拟列表，明确丢失、截断及写入失败；提供常用快捷键和深浅色主题。
- 第一版以基础调试闭环为目标；分屏、无线 ADB 配对向导、崩溃聚合、书签、自定义关键词配色和任意非 Logcat 文本解析留待后续。

## Capabilities

### New Capabilities

- `adb-devices`: ADB 发现与配置、设备管理、连接恢复、应用和进程元数据。
- `log-capture`: 共享采集、结构化日志、缓冲区配置、有界缓存及显示控制。
- `log-query`: 过滤语法、过滤收藏、搜索高亮、时间定位及上下文。
- `log-storage`: 录制、轮转、容量管理、导出和离线分析。
- `log-workspace`: 跨平台桌面界面、多标签页、偏好恢复及快捷键。
- `device-terminal`: 设备绑定的交互式 Shell 和会话生命周期。

### Modified Capabilities

无；当前目录没有现有应用代码或能力规格。

## Impact

- 新建桌面应用工程及上述六项能力；按已确认需求实施纯 Go 桌面应用。
- 采用 Go + Ebitengine + EbitenUI，终端使用 vt10x + Go Shell-v2；所有桌面平台支持 CGO_ENABLED=0，仅需 Go 编译器。
- 依赖用户本机 ADB 和各平台桌面图形运行环境；不修改系统 PATH，不捆绑 Android SDK。
- 配置与录制存储在本机；录制目录由用户指定，命令和日志不上传。
- 按项目约定不新增自动化测试；实施验收采用手动操作，编译遵守最小范围、进程互斥和不重复构建的约束，全量构建须先人工确认。
